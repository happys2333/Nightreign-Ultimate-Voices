# 黑夜君临 × 守望先锋中文大招播报 — 0.1.0 Beta

这是已内置十角色守望语音的成品包。安装只需要黑夜君临 **1.3.3.0** 和 **Mod Engine 3**；不需要安装守望先锋、Python、uv、Git 或 .NET SDK，也无需自行提取/编译语音。

## 选择版本

此文件是 **Native 原生动画版**，用于没有 MMV/其他玩家动作包覆盖 `chr/c0000.anibnd.dcx` 的环境。使用 MMVWeaponsMerge 的玩家应下载独立 **MMV-Addon**，按其说明添加到自己的现有配置；两个成品包互斥，不要叠加安装。

本机正向实测反馈来自当前 MMV 版本。原生版沿用相同的声音文件和触发参数，动画基底换回原版，已完成离线构建和恢复审计；本轮没有启动原生配置另做实机测试。

## 离线单人安装

1. 从 [ME3 官方发布页](https://github.com/garyttierney/me3/releases)安装 Mod Engine 3，保持 Steam 已启动。
2. 解压整个 `UltimateVoices-Overwatch` 文件夹到自己的模组目录，不要覆盖游戏安装目录。
3. 双击 `Launch.cmd`，或双击 `UltimateVoices.me3`。该配置关闭游戏官方在线功能。
4. 文件夹整体可以移动；`mod/`、启动器和 `.me3` 应保持在一起。

此配置不加载无缝联机，也不指定额外存档名称。要使用已有无缝存档，请按下一节操作。

## 无缝联机

已经有可用的 Seamless Co-op 时，可把自己的完整 `SeamlessCoop` 文件夹放在本包根目录，使 `SeamlessCoop/nrsc.dll` 存在，再双击 `Launch-Seamless.cmd`。本包不附该 DLL 或其他模组。

附带的无缝配置使用 `NR0000.co2`，与默认 `co2` 扩展的设置对应。如果你已经更改了无缝存档扩展、使用其他模组或不同启动设置，优先在自己的原始配置副本中追加本包，而不是用附带配置替换自己的设置。

将下面内容追加到你自己的 ME3 配置副本，修改 `path` 为从该配置文件到本包 `mod/` 的实际位置。此方法同样要求没有其他玩家动作包冲突：

```toml
[[packages]]
id = "nightreign-ultimate-voices"
path = "./UltimateVoices-Overwatch/mod"
```

不要通过普通官方匹配加载本模组。原始配置仍可用于停用模组，无需修改游戏归档。

| 追踪者 | 安燃，敌方大招 |
| 守护者 | 末日铁拳，敌方“毁天灭地！” |
| 铁眼 | 半藏，敌方大招 |
| 女爵 | 禅雅塔，友方“感受宁静。” |

| 隐士 / 法师 | 血律，敌方大招 |

守护者、铁眼在游戏接受大招输入并开始动作时播报；学者在约 3.3 秒收招时播报。保留蓄力、爆炸和命中音效，只移除已确认的专用原喊声调用。温斯顿选段为共用启动咆哮，不是敌方专属台词。

谁安装谁使用自己本机的声音，未安装者继续使用自己的原始资源；不向队友传输语音，不强制队友安装。队友播报依赖本机收到对应原生事件，远距离覆盖仍待专项验证。

## 兼容、性能与卸载

替换资源包括十个 `sd/hero*.bnk`、`sd/wem/` 新媒体、两个 `sound/` 事件目录和 `chr/c0000.anibnd.dcx`。与修改同一文件的动作/声音模组需要合并，不能只靠加载顺序解决。不能删掉声音目录或动画文件来尝试兼容，否则改过时机的角色可能无声。

游戏中没有新增本项目 DLL、常驻程序、扫描轮询、转码或网络协议。没有帧时间基准，不承诺零开销或提高 FPS。

停用：使用原启动配置；通过原配置副本追加的玩家，移除对应 `packages` 条目即可。没有安装程序，不需运行卸载器。

更换自定义语音需要单独的 Build Toolkit 重新构建，本成品包不提供游戏内导入/热切换界面。素材与代码说明见 `CREDITS.txt`。按角色替换 WAV 与恢复默认步骤见 `CUSTOM-AUDIO.md`。


自定义语音 / Custom audio: see CUSTOM-AUDIO.md for per-character WAV replacement, rebuilding and restoring defaults.
