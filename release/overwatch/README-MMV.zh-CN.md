# 守望大招播报 — MMVWeaponsMerge 兼容附加包 0.1.0 Beta

此成品附加包保留当前已经实测的 MMV 动画基底，语音、触发时刻和资源字节与本机已测版本一致。下载者无需 Python、.NET、编译器或守望安装。

## 适用输入

黑夜君临文件版本 **1.3.3.0**，MMVWeaponsMerge 的输入 `chr/c0000.anibnd.dcx` SHA-256 必须为：

```text
0eafca3631ddbbf3b2ec67edb49068bdc4ebcf5e4d48b2b1720a0a1c2921be69
```

这是未应用本语音包的 MMV 原始输入摘要，不是本包补丁输出摘要。可用 PowerShell 检查自己的 MMV 文件：

```powershell
Get-FileHash "C:\YourMMVFolder\chr\c0000.anibnd.dcx" -Algorithm SHA256
```

不匹配时不要将此文件覆盖到其他动作版本；需用构建器审核/合并自己的输入。不是所有名为 MMV 的版本都兼容。

## 安装到现有 ME3 配置

1. 保留你已经可用的 MMV、汉化和无缝联机安装。
2. 将本包 `UltimateVoices-MMV` 文件夹放在自己 `.me3` 配置旁，复制原配置作为语音专用启动配置。
3. 把 `ME3-PACKAGE.txt` 的 `[[packages]]` 条目追加到配置副本末尾。该示例假定原 MMV 包的 id 是 `MMVWeaponsMerge`；若不同，修改 `load_after` 中的 id。如果文件夹放在别处，也要修改相对路径。
4. 用该配置副本启动，沿用原配置的无缝设置和存档。不要再加载原生动画版或另一份 Ultimate Voices。

本包不提供独立启动器，因为它依赖你的既有 MMV 配置和其余资源。它包含在当前 MMV 基底上修改的动画文件，不是完整 MMV 模组，也不包含 MMV 的其他必要资源、Seamless Co-op DLL、汉化、存档或个人配置。
