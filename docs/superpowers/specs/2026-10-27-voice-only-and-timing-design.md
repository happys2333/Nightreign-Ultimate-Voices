# 原生喊声隔离与播报时机

用户授权的目标：仅去除角色原大招喊声，保留蓄力、爆炸、命中及普通动作声音；守护者和铁眼在成功进入大招起手时播报，学者在施法结束、恢复控制时播报。继续使用本机资产与原生事件，不加入游戏内扫描、输入钩子、计时进程或网络协议。不要求用户反复重启诊断。

## 时机

有效资源来自原 ME3 配置按优先级解析的 `chr/c0000.anibnd.dcx`，当前为 MMV 版本。构建时只增加四条独立声音事件：

| 角色 | TAE / 动画 | 新事件时间 |
| --- | --- | --- |
| 守护者地面 | 2901 / 610000 | 0 秒 |
| 守护者空中 | 2901 / 615000 | 0 秒 |
| 铁眼起手 | 2902 / 620000 | 0 秒 |
| 学者 | 2908 / 680000 | 3.3 秒 |

铁眼 620005 是由起手进入的提前释放续接，不增加第二条播报。学者 2.5 秒为技能成功生效点，3.3 秒是恢复操作权限的边界；不把它说成已确认的 HKX 最后一帧。动作在该事件前中断时不会执行后面的事件，避免独立定时器在取消后误播。

三个专用 Wwise Event 只含本地 OW 播报。原始释放事件、所有特效声音和控制动作保持原时机。TAE 使用原生 type128、SoundType1；新声音编号和 FNV 编号经过碰撞检查。必须回读验证整个 Binder 的成员、原有事件和属性不变，仅增加白名单四行。

## 喊声

现有 11 个挂载事件不等于纯人声，其中多段为数秒立体声效果。不能删除其完整 PlayAction。TAE 的 SoundType15 已证明按鞋、护甲和地面材质选择效果，也不能删除。只允许修改有来源证据的原生人声触发或专用人声参数；不得通过全局声音或总线静音影响其他动作。若人声与特效已合成在同一媒体，不能把整段删除冒充人声分离。

## 发布与验证

新增动画工具只在构建阶段运行，沿用本机游戏的 Oodle；生成包仅增加资产文件。原配置和游戏目录不写入。输出仍使用拥有清单和事务发布。校验包括合成回归、有效 MMV Binder 的无修改逐字节往返、四行差异审计、声音加载/事件预备加载的独立引擎验证，以及原特效保留。游戏和双客户端验收与离线检查分别记录。
