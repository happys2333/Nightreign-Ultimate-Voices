# 本地 OW 大招语音导入

本轮用户明确要求使用开源工具提取本机 OW 音频，并编写可复用组件。沿用已批准的“启动前离线转换 + Nightreign 原生事件/本地声库”设计；不新增游戏运行时组件。

## 数据路径

使用开源 OWLib/DataTool 读取本机 CASC，离线导出指定八英雄。因发布版不支持当前热修复，使用已实测的154504适配源码构建，保存原始提交/补丁和工具摘要。禁止用其他来源音频冒充本机提取。

从原生大招语音分组、字幕和条件元数据中选择敌/友方正确片段；保存英雄ID、资源GUID、相对路径、SHA-256和选择依据。不能仅凭“Ultimate”文件夹或第一条音频判断敌我版本。

离线导入组件核对源文件摘要及英雄/视角映射，调用开源解码工具将选中音频转为PCM16 WAV，沿用既有格式/时长/资源预算检查，生成单独 `voices.overwatch.json` 后构建本地模组。原始提取资源和OW音频不进入Git；只提交代码、映射与来源元数据。

## 验证

新增测试覆盖映射缺失、敌友混用、摘要变化、路径逃逸、工具返回成功但实际报错、转码失败不发布半成品，以及CLI接入。实际提取后复核八个音频、时长、字幕和视角证据，重新构建并验证八角色原生声库。
