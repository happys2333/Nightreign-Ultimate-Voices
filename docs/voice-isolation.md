# 大招原喊声隔离与播报时机

本次按“只去掉原大招喊声，保留蓄力、爆炸和命中音效”修改。没有静音整个技能、角色总线或全部战斗语音。

## 原喊声

在原生与当前 MMV 的全部 **25,600** 条玩家动画记录中，以下五个声音事件只出现在大招动画族。每个事件只有一个原始 Play Action，独立的人声/吼声媒体与蓄力、爆炸、命中媒体分开；构建只从这些 Event 的 Action 列表中移除下面的编号。

| 角色 | 原喊声事件 | 移除的 Play Action | 独立媒体数 | 动画范围 |
| --- | --- | ---: | ---: | --- |
| 无赖 | `Play_c000508100` | 302241724 | 3 | `a904:640000` |
| 复仇者 | `Play_c000607110` | 1065807488 | 3 | `a905:650000` |
| 复仇者 | `Play_c000607120` | 853917164 | 3 | `a905:650000` |
| 执行者 | `Play_c000808000` | 1016474030 | 2 | `a907:670000` |
| 送葬者 | `Play_c001007110` | 703259875 | 3 | `a909:690000/690010/695000/695010` |

执行者这一项是原变身吼声，保留 OW 温斯顿吼声。其 `Play_c000807501` 是变身音效层，完整保留。无赖的原事件继续播放新增 OW 声音；其他四个纯原喊声 Event 保留为空事件。Action、Sound 节点与媒体文件本身均保留，其他事件对原资源的调用不受修改。

`config/characters.json` 中的 `native_vocals` 固定了原声库、Event 载荷和 Action 载荷的 SHA-256。任一输入不匹配都会拒绝构建。仅启用该角色时应用移除；未配置或关闭的角色维持原资源。其他角色没有在本次大招资源中发现需要单独移除的专用喊声事件，因此保留其技能音效，不整段删除法术或效果音。

定位结合了原生 Wwise 层级、单声道变体、皮肤切换、动画使用范围、无赖此前的实际反馈及离线音频分类。分类仅作为研究辅助，不能作为混音分离或游戏听感验收证明；模型不进入构建依赖或游戏包。普通攻击、受击语音、对话、鞋底/护甲材质声均未整体静音。

## 三个角色的播报时机

| 角色 | 新声音事件 | TAE / 动画 | 播报位置 |
| --- | --- | --- | --- |
| 守护者 | `Play_c900207000` | `2901 / 610000`、`2901 / 615000` | 地面及空中大招动作开始，0 秒 |
| 铁眼 | `Play_c900307000` | `2902 / 620000` | 大招动作开始，0 秒 |
| 学者 | `Play_c900907000` | `2908 / 680000` | 收招、恢复操作的边界，3.3 秒 |

这里的“按下”是游戏接受输入并开始大招动作；冷却中按键不会播报。铁眼提前释放 `620005` 是从 `620000` 续接，不再添加声音，避免一招播报两遍。学者效果在约 2.5 秒生效，新播报在其后，不挂在开场音效上。中断和最后一帧切换的实际表现仍需游戏验收。

修改后的角色声库新增独立声音 Event，借用已验证的原事件输出总线；三个角色原本挂载 OW 的旧事件恢复为原始 Action 列表。所有原有音效时刻保留。

当前 MMV 动画包有 623 个成员，只改 `a901.tae`、`a902.tae`、`a908.tae`，共追加四条 type-128 声音事件及独立分组。其余成员、原事件、动作参数、伤害/效果时机和分组均核对保留；去掉新增条目并还原零字节对齐后，目标 TAE 与输入逐字节一致。格式及对齐审计见 `tools/tae/README.md`。

构建优先读取原 ME3 配置的实际动画覆盖文件，只接受已审核的原生或当前 MMV 完整文件摘要。遇到其他动画包会拒绝覆盖。无需修改已有 MMV、游戏归档、HKS、regulation 或存档。

## 验证边界

独立 Wwise 引擎验证新增声音的直接加载与事件预备加载，并对原喊声事件做“原始有声 / 修改后静音”对照。静态审计比较全部原音频媒体及非目标对象。动画工具在构建时运行，游戏中没有新增进程、DLL、轮询或网络消息。

这些验证不能代替实际游戏的动画触发顺序、听感、取消边界和双客户端联机验收。谁安装谁使用自己的本地资源；未安装队友的原文件不会被修改。
